# 峡谷对决 - 网页 5v5 MOBA 小游戏

纯原生 HTML + CSS + JavaScript 实现的 5v5 推塔对战游戏，零依赖、单文件，浏览器打开即玩。

**在线试玩**：https://microstonedev.github.io/canyon-showdown/

## 游戏文件

| 文件 | 说明 |
|---|---|
| `index.html` | 落地页（GitHub Pages 入口） |
| `moba.html` | 峡谷对决（5v5 MOBA 推塔对战） |
| `champions.html` | 英雄卡通建模设计图 |

## 怎么玩

打开 `index.html`（落地页）或 `moba.html` 即可——无需安装任何东西，也无需本地服务器。在登录界面输入名字（最多 10 个字符）并选择语言——中文 或 English——全部菜单、播报与符文说明都会跟随所选语言。

## 峡谷对决玩法

### 操作

- `W A S D` — 移动
- `鼠标` — 瞄准（光标触碰屏幕边缘时镜头平移，`空格` 回中）
- `左键` — 普通攻击（可长按）；箭矢从武器中点射向鼠标所指位置
- `右键` — 释放技能（3 级解锁）
- `Q` — 使用道具（钩子）
- `ESC` — 设置 / 暂停
- `M` — 静音
- `滚轮` — 缩放视角

### 规则

- 5v5 对战：你 + 4 名 AI 队友 对阵 5 名 AI 敌人，地图为 2000 × 900 的宽幅两路战场
- 每条路每方两座防御塔（外塔 + 内塔），全图共 8 座；水晶会攻击进入范围的敌人
- 摧毁敌方水晶获胜
- **防御塔弹道锁定必中**：开火后追踪目标、跑多远都会被追上、无法闪避——只能在它开火前离开射程，或叫队友一起越塔
- **经验只来自击败敌方英雄**：击杀 170 经验，助攻 100（需在目标死亡前 8 秒内对其造成过伤害）；每级消耗 100 经验，对局通常在 8~9 级时结束
- 升级提升生命、普攻和技能伤害，3 级解锁技能，最高 9 级
- 脱离战斗（攻击也算战斗）5 秒后每秒回复 5% 生命；泉水仅作复活点
- 英雄攻击均为非指向性弹道，可以走位躲避；岩石阻挡移动与弹道（防御塔追踪弹除外），草丛提供隐身
- **连杀播报**：10 秒窗口内连续击杀触发双杀/三杀/四杀/五杀全屏公告
- **MVP 结算**：对局结束时按 击杀×3 + 助攻×1.5 − 阵亡×2 + 输出/400 评选全场最有价值玩家

### 界面（HUD）

- 右上角 — 你的 K / D / A
- 血条左侧 — 自身数值面板：攻击力、攻速、移速、技能急速（拥有对应符文时另显示暴击/闪避/吸血/减伤）
- 血条上方 — 已拥有的海克斯图标及其**实时叠加数值**（超凡邪恶攻击、坦克引擎层数、无限循环急速、风暴聚集、威能追求等）

### 四个角色

| 角色 | 特点 | 技能 |
|---|---|---|
| 🏹 射手 | 远程弹道、高攻速 | 穿云箭：超远穿透箭 |
| 🗡️ 刺客 | 近战 45° 正面窄判定、高爆发、不能隔墙攻击 | 影袭：突进（撞墙即停） |
| 🛡️ 肉盾 | 近战整圆范围、厚血 | 震地：范围伤害+减速 |
| ✚ 辅助 | 远程弹道，普攻打到队友会治疗 | 圣光波：伤害敌人并治疗途经友军 |

### 海克斯强化符文（2 / 5 / 8 级）

2、5、8 级时对局暂停，三选一获得永久强化——参照大乱斗海克斯，分为**棱彩**（25%，强力）与**黄金**（75%，常规）两档；全英雄共用同一池子，每局每个符文限选一次，叠加数值实时显示在血条上方。

- **棱彩**：🎲 掷骰狂人 · ♾️ 无限循环往复 · 🚜 坦克引擎 · 😈 超凡邪恶 · 🔮 珠光护手 · 🗡️ 双刀流 · 🦵 飞身踢 · 🎯 威能之追求
- **黄金**：💖 圣光祝福（仅辅助）· 🩸 吸血习性 · 🔬 缩小引擎 · 👻 灵魂虹吸 · 👹 你肩上的恶魔 · 🧪 科学狂人 · 💪 大力 · 🔨 巨人杀手 · 🌌 星界躯体 · 🪶 灵巧 · ⏱️ 疾速之追求 · ✊ 不灭之握 · 💀 黑暗收割 · ⛈️ 风暴聚集

### 远古增益（团队稀有道具）

每局约三次，河道线（上方 / 中央 / 下方随机一处）刷新一枚远古结晶——**提前 25 秒全服预告**并在落点显示倒计时提示圈。谁拾取，**谁的全队每人**就永久获得随机强化：⚔️ 攻击+12 · ❤️ 生命+90 · 👟 移速+20 · ⏱️ 急速+15 · 🛡️ 受伤-4%。场上同时只存在一枚，45 秒无人拾取会消散——围绕它的争夺是中期团战的引爆点。

### 地图

在登录界面选择地图——悬停卡片查看说明，选择会被记住。

- **草地** — 经典布局：河道、岩石与均衡的草丛
- **熔炉** — 岩浆河与岩浆池：踏入岩浆减速 40%，每秒灼烧 6% 最大生命（不会致命）；AI 会绕行
- **丛林** — 更多更大的草丛、视野受限——埋伏天堂

### 场上道具（随机刷新）

❤️ 血包 · 🛡️ 护盾 · 👻 隐身 · 👟 疾跑 · 🪝 钩子（Q 发射，把敌人勾到身前）

## 技术说明

- 单 HTML 文件，Canvas 2D 渲染，`requestAnimationFrame` 主循环
- 英雄模型使用矩形命中框；防御塔弹道为锁定追踪必中，英雄弹道为可躲避的技能弹
- AI 具备走位躲弹道、绕岩石、残血拉扯、抢道具、出钩、争抢远古增益等行为
- 音效与背景音乐全部由 Web Audio API 实时合成，零音频素材；生成式芯片 BGM 在菜单/战斗间自动切换强度
- 音频设置（主音量 / 音乐 / 音效、静音）在 ⚙ 按钮或 `ESC` 中；游戏中打开会暂停比赛，设置经 `localStorage` 持久保存
- 支持简体中文 / English 双语界面，登录时选择
- 无任何外部库、无构建步骤、无网络请求
